# 银行编码

| `bankCode` | 银行名称 |
|---|---|
| `004` | Kookmin Bank |
| `020` | Woori Bank |
| `088` | Shinhan Bank |
| `081` | KEB Hana Bank |
| `011` | NongHyup Bank |
| `003` | Industrial Bank of Korea |
| `090` | Kakao Bank |
| `089` | K Bank |
| `092` | Toss Bank |
| `023` | Standard Chartered Korea |
| `032` | BNK Busan Bank |
| `039` | BNK Kyongnam Bank |
