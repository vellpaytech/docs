# 银行编码

创建巴西代付订单时，`bankCode` 使用巴西银行 COMPE 编码。

| `bankCode` | 银行名称 |
|---|---|
| `001` | Banco do Brasil |
| `033` | Banco Santander Brasil |
| `104` | Caixa Econômica Federal |
| `237` | Banco Bradesco |
| `260` | Nu Pagamentos |
| `341` | Itaú Unibanco |
| `077` | Banco Inter |
| `336` | C6 Bank |

`payoutType` 表示 PIX Key 类型，不是银行编码。银行编码与 PIX Key 应分别传入对应字段。
