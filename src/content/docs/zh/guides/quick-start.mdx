## 简介

VellPay 为跨境商户提供多国家本地代收、代付、订单查询、余额查询、收银台及特定国家扩展能力。商户可以使用一致的字段模型接入不同国家，并根据国家选择对应支付方式。

当前覆盖亚洲的印度尼西亚、越南、韩国、柬埔寨、印度，以及拉丁美洲的哥伦比亚、阿根廷和巴西。

## 接入步骤

<Steps>

1. **开通测试权限**

   确认需要接入的国家、业务类型、费率、结算周期和上线计划。VellPay 将创建测试商户、应用及国家权限，并提供测试 `appId`、商户后台账号和对接联系人。

2. **准备应用密钥**

   根据[创建密钥](/zh/guides/create-keys/)生成商户 RSA 密钥对。在商户后台配置商户公钥，并妥善保存商户私钥和平台公钥。

3. **实现请求鉴权**

   请求统一携带[公共请求头](/zh/guides/request-headers/)，并按照[接口鉴权](/zh/guides/authentication/)生成 `authorization`。

4. **选择国家接口**

   从左侧选择业务国家，确认支付方式、字段格式、金额限制和当地时间规则，然后按业务需要接入代收、代付、查询、余额或收银台接口。

5. **完成联调**

   在接口页点击“模拟请求”，核对请求 Header、JSON Body 和响应内容；验证正常与异常参数、订单查询、回调验签、重复回调和幂等处理。

6. **生产上线**

   确认生产商户、生产应用、公钥交换、IP 白名单和回调地址已配置。建议先使用小流量验证创建成功率、支付成功率及回调处理，再逐步扩大流量。

</Steps>

:::note
文档调试功能只允许访问 VellPay 测试环境，不会向生产环境发送请求。
:::

## 接入前检查

- 商户应用和目标国家权限已经启用。
- 对应支付方式及费率已经配置。
- 商户公钥已经上传，平台公钥已经安全保存。
- 服务器出口 IP 已加入白名单。
- 测试回调地址可以通过公网 HTTPS 访问。
- 服务器时间已通过 NTP 同步。
