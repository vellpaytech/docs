<p class="endpoint-lead">查询总余额、冻结金额和当前可用余额。</p>

<div class="method-path"><strong>POST</strong><code>/trade/merchant/balance</code></div>

本接口没有业务请求参数，仅需传递[公共请求头](/zh/guides/request-headers/)。

## 响应参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `code` | int | 是 | - | 状态码，非 200 代表异常 |
| `data` | Object | 是 | - | 响应体 |
| `data.totalAmount` | String | 是 | 20 | 总金额 |
| `data.frozenAmount` | String | 是 | 20 | 冻结金额 |
| `data.availAmount` | String | 是 | 20 | 当前可用余额 |
| `msg` | String | 否 | - | 异常信息 |
| `tid` | String | 是 | - | traceId |
