# 银行编码

创建阿根廷代付订单时，`bankCode` 使用以下三位银行编码。CVU 和 CBU 账户均使用相同编码体系。

| `bankCode` | 银行名称 |
|---|---|
| `007` | Banco de Galicia |
| `011` | Banco de la Nación Argentina |
| `014` | Banco de la Provincia de Buenos Aires |
| `017` | BBVA Argentina |
| `027` | Banco Supervielle |
| `029` | Banco de la Ciudad de Buenos Aires |
| `034` | Banco Patagonia |
| `072` | Banco Santander Argentina |
| `150` | HSBC Bank Argentina |
| `285` | Banco Macro |

银行编码可能随本地清算网络调整；未列出的银行请向 VellPay 商务或技术支持确认后再提交。
