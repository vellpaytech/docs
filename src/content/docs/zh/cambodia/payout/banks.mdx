# 银行编码

| `bankCode` | 银行名称 |
|---|---|
| `0001` | ABA Bank |
| `0002` | Wing Bank |
| `0005` | Sathapana Bank |
| `0006` | ACLEDA Bank |
| `0007` | Phillip Bank |
| `0008` | Phnom Penh Commercial Bank |
| `0010` | Canadia Bank |
| `0015` | KB PRASAC Bank |
| `0021` | Maybank Cambodia |
| `0051` | Woori Bank Cambodia |

银行编码适用于 `BANK_TRANSFER` 和 `BANK_TRANSFER_USD`。其他银行请向 VellPay 确认当前是否已开通。
