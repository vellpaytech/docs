# 银行编码

| `bankCode` | 银行名称 |
|---|---|
| `1001` | Banco de Bogotá |
| `1002` | Banco Popular |
| `1006` | Banco Itaú |
| `1007` | Bancolombia |
| `1009` | Citibank Colombia |
| `1012` | Banco GNB Sudameris |
| `1013` | BBVA Colombia |
| `1032` | Banco Caja Social |
| `1051` | Davivienda |
| `1062` | Banco Falabella |

使用 `PHONE` 或 `BREB` 时，账户字段规则可能不同，但 `bankCode` 仍应使用已开通机构对应编码。
