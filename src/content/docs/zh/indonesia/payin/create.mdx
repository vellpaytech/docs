<p class="endpoint-lead">使用统一字段创建代收订单。支付方式和必填字段根据请求所属国家确定。</p>

<div class="method-path"><strong>POST</strong><code>/trade/payment/create</code></div>

使用[公共请求头](/zh/guides/request-headers/)。

## 请求参数

| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `merchantOrderNo` | String | 是 | 32 | 商户订单号 |
| `transactionAmount` | String | 是 | 20 | 收款金额 |
| `paymentType` | String | 是 | 24 | 支付方式 |
| `idType` | String | 是 | 32 | 用户证件类型 |
| `userIdCard` | String | 是 | 32 | 用户证件号码 |
| `userName` | String | 是 | 64 | 用户姓名 |
| `userPhone` | String | 是 | 20 | 用户手机号 |
| `userEmail` | String | 是 | 50 | 用户邮箱 |
| `bankCode` | String | 否 | 20 | 银行编码 |
| `bankAccountNo` | String | 是 | 20 | 银行账户 |
| `merchantName` | String | 是 | 20 | 商户名称 |
| `description` | String | 是 | 100 | 说明 |
| `accountHolderNumber` | String | 否 | 20 | 账户持有人识别码，格式 YYMMDD |
| `ipAddress` | String | 否 | 64 | 付款人 IP 地址 |
| `channel` | String | 否 | 64 | 支付方式扩展字段 |
| `expireTime` | String | 是 | - | 订单过期时间，使用国家当地时间 |
| `paymentCallbackUrl` | String | 否 | 200 | 代收回调地址 |

## 请求示例

```json
{
  "merchantOrderNo": "ORDER202609170001",
  "transactionAmount": "100.00",
  "paymentType": "PAYMENT_TYPE",
  "userName": "TEST USER",
  "userPhone": "6123456789",
  "userEmail": "user@example.com",
  "paymentCallbackUrl": "https://merchant.example/callback"
}
```

## 响应参数

| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `code` | int | 是 | - | 状态码，非 200 代表异常 |
| `data` | Object | 是 | - | 响应体 |
| `data.merchantOrderNo` | String | 是 | 24 | 商户订单号 |
| `data.tradeNo` | String | 是 | 24 | 平台单号 |
| `data.transactionAmount` | String | 是 | - | 收款金额，整数或保留 2 位小数 |
| `data.status` | String | 是 | 24 | 订单状态 |
| `data.paymentType` | String | 是 | 24 | 支付方式 |
| `data.failMsg` | String | 否 | 200 | 订单失败原因 |
| `data.paymentInfo` | String | 否 | 200 | 支付信息 |
| `data.additional` | Object | 否 | - | 附加信息 |
| `msg` | String | 否 | - | 异常信息 |
| `tid` | String | 是 | - | traceId |
