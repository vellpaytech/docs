# 银行编码

| `bankCode` | 银行或钱包 |
|---|---|
| `0001` | Bank BRI |
| `0002` | Bank Mandiri |
| `0003` | Bank BNI |
| `0005` | Bank Permata |
| `0007` | Bank BCA |
| `0010` | CIMB Niaga |
| `0012` | OCBC NISP |
| `0018` | Bank DBS |
| `0074` | Bank BTN |
| `0081` | Bank Syariah Indonesia |
| `dana` | DANA |
| `gopay` | GoPay |
| `ovo` | OVO |

编码区分大小写时以表中值为准。未列出的银行或钱包请向 VellPay 确认当前可用编码。
